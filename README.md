# 우리 아기 말 수첩

아기가 말하거나 알아들은 단어를 날짜와 함께 기록하는 단순 기록장입니다.
영유아검진 문진표를 쓸 때 참고할 수 있도록 요약 화면과 복사용 텍스트를 제공합니다.

- 언어 발달을 평가하거나 판단하지 않습니다. 월령별 기준·또래 비교 기능은 의도적으로 넣지 않았습니다.
- 기록은 브라우저 localStorage에만 저장됩니다. 서버로 전송되지 않습니다.
- 백업 파일(.json) 받기/불러오기로 기기 간 이동이 가능합니다.

## 구조

빌드 없는 단일 정적 페이지(`index.html`)입니다. Vercel에서 Framework Preset을 "Other"로 두고 그대로 배포하면 됩니다.
